# Supervision Température, Humidité et Sol (Node-RED)

Projet de supervision IoT développé sous Node-RED avec Dashboard 2.0 et base de données InfluxDB.

## Installation et lancement

1. Cloner ce dépôt sur votre machine.
2. Installer les dépendances nécessaires :
   ```bash
   npm install
   ```
3. Démarrer le serveur Node-RED :
   ```bash
   npm start
   ```
4. Accéder aux interfaces :
   * **Éditeur Node-RED :** `http://localhost:1880/red`
   * **Tableau de bord (Dashboard) :** `http://localhost:1880/dashboard`
